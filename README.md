## 原生IP 到底指什么

原生IP 不是 RFC 标准里的术语，是行业对"高信任度本地出口 IP"的通俗说法。要同时满足几条才算：IP 由目标地区的本地 ISP 直接分配；没有经过代理、NAT、隧道或共享池中转；ASN、PTR 记录、地理位置与普通家庭用户一致；在平台风控系统里不带代理或数据中心标签。

| 维度 | 原生 IP（理想状态） | 常见非原生 IP |
| --- | --- | --- |
| 来源 | 本地 ISP 直连家庭或企业宽带 | 云服务器、IDC 机房、代理池、VPN 节点 |
| ASN 类型 | 标记为 ISP 或 Residential | 标记为 Hosting、Cloud、Business |
| PTR 反向 DNS | 无记录或 ISP 域名 | 含 server、vps、cloud 等关键词 |
| IP 分布 | 分散，无明显规律 | 成段分配，地理集中 |
| 平台信任度 | 首次请求通过率较高 | 容易触发验证码、限流 |

一个容易混淆的点：住宅 IP 不等于原生 IP。部分住宅代理通过 P2P 网络或 SDK 共享带宽，IP 来源确实是家庭宽带，但"被代理使用"这个行为本身会留下异常痕迹，风控照样能识别。反过来，机房里也有 ASN 归属本地运营商的 IP，那属于原生，但不属于住宅。

## 自己动手验：四条命令

买之前验一遍，比看商家页面上的"原生IP"四个字可靠。

**查 ASN 与组织信息**。打开终端：


curl https://ipinfo.io/8.8.8.8/json


把 8.8.8.8 换成你拿到的 IP。`org` 返回 `AS15169 Google LLC` 这类，是数据中心段；返回 `AS7922 Comcast Cable Communications` 这类本地运营商，才是住宅候选。ipinfo.io 和 bgp.he.net 都能查，前者给结构化字段，后者看路由归属更直观。

**查 PTR 反向 DNS**：


dig -x 8.8.8.8 +short


返回 `google-public-dns-a.google.com` 这种带公司名的，基本可以判定非原生；返回空值，或者返回类似 `xxx.hinet.net` 的运营商域名，更接近原生。Windows 下用 `nslookup 8.8.8.8` 效果一样。

**看风险评分**。Scamalytics 给 0 到 100 的风险分，低于 50 相对可信；IPQualityScore 会给代理和 VPN 的概率评分，两项都干净再考虑下单。

**浏览器指纹辅助判断**。访问指纹检测页，出现 "Proxy detected" 或 "WebRTC leak" 说明链路上有代理痕迹。所有字段都是本地 ISP 默认值，才谈得上接近原生。

这四步里，ASN 和 PTR 是硬指标，风险分和指纹是佐证。只改归属地显示、不改 ASN 的 IP，在第一步就会露馅。

## FAQ

**原生IP 一定不会被封号吗？**
不一定。没有任何 IP 能保证 100% 不封。原生 IP 只是降低被判定为代理或数据中心的概率，账号行为、设备指纹、操作节奏同样进风控模型。真实住宅 IP 被大量滥用后一样进黑名单。

第三方测评记录这批产品仅提供 Linux。需要 Windows 环境的话，先向客服确认具体套餐是否支持，不要默认可以。

**年付还是月付？**
WePC 官网标价是澳元月付，公开页面上没有看到年付折扣信息。月付试错成本低，先跑一个月验证 IP 属性和线路质量，确认能用再考虑长期。

**TikTok 选英国还是日本？**
看你的目标市场。做英国区内容选英国节点，做日本区选日本节点，IP 归属地和账号注册地、内容语言要一致。跨区使用会削弱原生 IP 的价值。
